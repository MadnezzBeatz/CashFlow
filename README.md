# CashFlow
## Шаг 1: клонирование репозитория
```python
git clone <URL_вашего_репозитория>
cd <имя_папки_проекта>
```
## Шаг 2: установка виртуального окружения и библиотек
1) Создайте виртуальное окружение
```python
python -m venv venv
```
2) Активируйте для windows
```sh
venv\Scripts\activate
```
   Для linux
```sh
source venv/bin/activate
```
## Шаг 3: Настройка зависимостей и БД
1) Создайте миграции
```python
python manage.py makemigrations
```
2) Примените миграции
```python
python manage.py migrate
```
3) Создание супер-пользователя
```python
python manage.py createsuperuser
```
## Шаг 4: Запуск сервера и заполнение базы данных
1) Запустите сервер
```python
python manage.py runserver
```
2) Перейдите по ссылке
    http://127.0.0.1:8000/admin
   И войдите под супер-пользователем, которого создали ранее
3) Заполните таблицу status
4) Заполните таблицу type
5) Заполните таблицу category указывая type к каждой записи
6) Заполните таблицу subcategory указывая category к каждой записи
7) Заполните таблицу records
## Шаг 5: Просмотр и фильтрация записей
1) Перейдите по ссылке http://127.0.0.1:8000, на этой странице вы можете просматривать записи о движении денежных стредств
2) Выберите необходимые фильты и нажмите кнопку "Фильтровать"
